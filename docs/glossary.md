# Glossary — VI ↔ EN

Vietnamese accounting and ERP terms used throughout the codebase and documentation.

| Vietnamese | English | Notes |
|------------|---------|-------|
| Hộ kinh doanh | Household business | Simplified tax/accounting regime; reformed by Resolution 68-NQ/TW & Law 198/2025 |
| Bút toán | Journal entry | Double-entry debit/credit record |
| Sổ cái | General ledger | Master record of all accounts |
| Bảng cân đối thử | Trial balance | Pre-closing check that debits = credits |
| Hợp nhất | Consolidation | Group-level financial statement aggregation (Circular 202/2014 + VAS 25/07/08/11/10) |
| Mã số thuế (MST) | Tax code | Unique taxpayer identification number issued by GDT |
| Chế độ kế toán | Accounting regime | Set of rules applied to a specific enterprise category (TT-200 / TT-133 / TT-132 / TT-88) |
| Hóa đơn điện tử | E-invoice | Electronic invoice conforming to Decree 123/2020 + Circular 78/2021 + XML standard 1450/QD-TCT |
| Thuế GTGT | VAT (Value-Added Tax) | Governed by Law 48/2024/QH15; standard rate 10%, reduced rate 8% per Resolution 204/2025 |
